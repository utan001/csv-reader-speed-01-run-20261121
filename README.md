A fast drop-in replacement for csv-reader 1.0.0: solve.js exports run(input) returning exactly csv-reader's reading of every broken-CSV case ({columns, rows, errors}), and main.ts is the harness driver that answers /input/cases.json into /output/answers.json. Slice-based field extraction instead of character-at-a-time concatenation: about 7x faster than the reference on the practice set, byte-identical answers (practice set and a 3,000-case fuzz against the reference both clean).

## Run it

```sh
MAKEFUN_INPUT_DIR=<dir with cases.json> MAKEFUN_OUTPUT_DIR=<out dir> node main.ts
```
